# Translation review

The site is published in 7 languages: English (default), French, Spanish, German, Italian,
Simplified Chinese and Polish. Every page, form, footer, legal page, FAQ, meta tag, image alt text,
the project planner and the assistant's answers are translated.

**Please have a native speaker review the strings listed below before launch.** French matters most.

## Where translations live

| File | What it holds |
|---|---|
| `i18n/en.json` | Every English string on the site (1,009 keys). Generated — do not edit by hand. |
| `i18n/<lang>.json` | The same keys, translated. Values may contain the same inline tags as the English (`<a>`, `<b>`, `<span>`…). |
| `i18n/planner/<lang>.json` | Planner questions and options. |

To change a translation, edit the value in `i18n/<lang>.json` and rebuild (`node build/build.mjs`).
After changing English copy, run:

```
node build/build.mjs --en-only
node tools/i18n-sync.mjs <dir-with-source-pages>   # refreshes en.json, keeps existing translations
node build/build.mjs
node tools/i18n-check.mjs                          # lists missing keys and English left on translated pages
```

`node tools/i18n-check.mjs` exits with an error code if anything is missing, so it can run in CI.

## Where each translation came from

1. **Your own translated pages** (skillstravelscontent.netlify.app in each language) were aligned with
   the English pages and reused wherever the text matched. These are your wording, unchanged.
2. **Gaps were filled by Claude** — strings that are newer than your translated pages, or that the
   alignment could not match with confidence:

| Language | From your pages | Written by Claude | Register used |
|---|---|---|---|
| French | ~810 | ~200, then the **whole French file was reviewed** and 44 mismatched pairs corrected | vous |
| Spanish | ~600 | ~430 | tú (matches your pages) |
| German | ~600 | ~430 | Sie |
| Italian | ~600 | ~430 | tu |
| Chinese | ~570 | ~460 | 您 |
| Polish | ~590 | ~440 | Ty (capitalised Twój/Twoje, as on your pages) |

Counts are approximate. If in doubt, review the whole file for that language — strings are short
and sorted alphabetically by their English key.

## Points to check

- **Your source translations may lag behind the English.** Where your English pages were updated after
  the translations, the older translated wording was *not* reused (the alignment rejects pairs whose
  length or structure no longer matches) — those strings were rewritten from the current English.
  A few short labels on your translated pages were still in English ("Famous for", "Your brief",
  "Coordination", "Water jousting"…); they are now translated.
- **Legal pages** (legal notice, privacy, cookies, accessibility) contain placeholders in square
  brackets — e.g. *[share capital]*, *[Name the AI provider…]*. They are translated as placeholders and
  must be completed in every language once the facts are confirmed.
- **Hero line.** "France begins before you land." / "Your journey begins before you land." — check the
  rhythm in each language; German uses *Frankreich beginnt, bevor Sie landen.*
- **French typography** uses a narrow no-break space before `? ! : ;` and typographic apostrophes (’).
- **Proper nouns kept as-is:** Formaskills Travel, Erasmus+, FLE, SIREN/RCS, street addresses, photo
  file names and licences. City names are localised where a local form exists (Nice → Niza / Nizza /
  Nicea / 尼斯; Paris → París / Parigi / Paryż / 巴黎).
- **Job shadowing** is kept as the English term in ES/DE/IT/PL (as Erasmus+ material does);
  Chinese uses 跟岗学习.
- **Emails** generated by the planner and contact forms use the visitor's language for labels and the
  subject line; the visitor's own answers are sent as typed.

## Not machine-checkable

- Tone and marketing feel of headings.
- Whether "Intermediate/Advanced" level names match the CEFR wording your teachers use.
- Erasmus+ terminology per country (National Agency names are kept generic on purpose).
